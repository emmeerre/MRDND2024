D&D 5ª Edizione

✦ Dati Incantatore — Valori predefiniti per tutte le card

💡 Come aggiungere un incantesimo: crea un file di testo chiamato esattamente ListaIncantesimi.txt (con la "I" maiuscola) nella stessa cartella di questo file HTML su GitHub.
All'interno del file, inserisci un array JSON valido. Ricorda: tutte le chiavi devono avere le virgolette (es. "name", non name) e non devono esserci campi duplicati.
📝 Grassetto: usa <b>testo</b> nella descrizione.
⚙️ Componenti: imposta "verbal", "somatic", "material" a true/false.
🛡️ Tiro Salvezza: inserisci la stat e l'saveOutcome (es. "Dimezza", "Annulla").
🎯 Tiro per colpire: imposta "toHit": true per mostrare il bonus.
📄 Pagine: usa "pageNumber": "1/2". Se diverso da "1/1", appare in alto a destra.
🚫 Nascondi Tabella: imposta "hideTable": true per lasciare più spazio al testo.
